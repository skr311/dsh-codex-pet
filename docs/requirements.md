## 1. 项目概述

为 DeepSeek Harness（DSH，Web GUI）开发一个插件：可以**导入/上传由 codex 生成的桌面宠物**（精灵图序列帧资产），并在 DSH Web GUI 中**渲染为悬浮、可交互的宠物**。UI 严格遵循 DSH 插件设计规范（Slot 注册、主题令牌、primitives 复用、生命周期管理、宿主↔客户端私有 RPC，详见 [development-spec.md](development-spec.md)）。

## 2. 已确认的关键决策（用户澄清结论）

| 决策项 | 结论 |
| --- | --- |
| 资产格式 | 精灵图序列帧（sprite sheet / 逐帧 PNG），非 Live2D |
| 导入方式 | ① GUI 上传文件/压缩包；② URL 下载（多选，均采纳） |
| 渲染位置 | 全应用悬浮、可拖拽浮层（shell.overlay） |
| 交互范围 | 纯展示动画 + 基础交互（点击/拖拽/随机动作）+ 与 Agent/会话状态联动（全部采纳） |
| 交付形态 | 打包 npm 插件（声明 dsh.bundle + dsh.client，持久安装到 profile） |
| 宠物管理 | 需要宠物图库/管理页 |

## 3. 功能需求

### FR-1 宠物资产导入
- **FR-1.1 GUI 上传**：网页内选择本地 zip 压缩包上传，解包、校验、入库。
- **FR-1.2 URL 下载**：粘贴远程 zip 地址，由宿主侧下载并入库。
- **FR-1.3 校验**：校验资产包结构（manifest 必填、贴图存在、帧参数合法），失败给出可读错误。
- **FR-1.4 幂等**：重复导入同一宠物给出提示或允许覆盖（待定策略，默认提示重名）。

### FR-2 宠物渲染
- **FR-2.1 悬浮浮层**：宠物渲染在全局浮层（shell.overlay）上，位于 GUI 之上，默认右下角。
- **FR-2.2 动画循环**：按 manifest 定义播放序列帧（FPS、帧宽高、动画组切换）。
- **FR-2.3 缩放/尺寸**：支持按 manifest 基准缩放，浮层大小随宠物比例自适应；提供**全局宠物大小设置**（图库页滑块 50%~200%，默认 100%，宿主侧持久化、跨重启保留，缩放变化带平滑过渡动画）。
- **FR-2.4 开关控制**：可显示/隐藏宠物（快捷入口 + 持久化用户偏好）。

### FR-3 交互
- **FR-3.1 拖拽**：浮层可拖动，位置持久化。
- **FR-3.2 点击反应**：点击宠物触发一次随机动作动画。
- **FR-3.3 随机动作**：空闲时按概率/间隔随机播放非空闲动画后回到 idle。
- ~~FR-3.4 说话气泡~~（已移除：用户决定不做）。

### FR-4 与 Agent/会话状态联动
- 空闲 / 思考 / 工作中 / 任务完成时播放对应动画组。
- 状态来源：优先读取会话槽位标准 props（useSessions / useProjection）中可用的会话/Agent 状态；若该状态不可用，则降级为基于最近活动的事件驱动或定时随机（实现期验证，见 [execution-steps.md](execution-steps.md) 的 S2）。

### FR-5 宠物图库/管理页
- 独立管理界面（settings.section 或等效设置槽位）：
  - 宠物列表（缩略图/名称/来源/状态）
  - 预览（在管理页内播放动画）
  - 选择"启用"当前宠物（全局同时只显示一只）
  - 删除（连带清理宿主存储）
  - 上传/URL 导入入口

### FR-6 持久化
- 宠物资产与用户偏好存于宿主磁盘专用目录（位于 DSH 用户根目录下，默认 $DSH_HOME/pets）。
- 重启 DSH 后宠物列表与当前启用项仍存在；浮层位置、显隐偏好持久化。

## 5. 非功能需求

- **性能**：序列帧播放使用单个 <img>/canvas + 定时器，避免高频重排；动画在宠物隐藏时停止。
- **安全**：URL 下载由宿主侧执行并校验 zip 结构与 manifest，防止任意路径写；上传文件大小设上限（默认 50MB）。
- **规范**：全部 UI 用 Slot 注册 + 主题令牌 + primitives；订阅/定时器全部随生命周期清理，不产生全局副作用。
- **兼容**：深色/浅色主题自适应；不依赖任何被禁止的全局 API。
